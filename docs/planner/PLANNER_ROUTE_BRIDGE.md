# Pressure Planner on the Academy website

Pressure Planner is in development. The public Academy homepage introduces it in the brand family at `/#pressure-planner`.

Legacy `/planner` addresses, including nested paths and `/planner/index.html`, temporarily redirect to that introduction. The static index provides the same destination when served outside Vercel. The homepage is the discovery URL in the sitemap and public site guide.

Planner application source and hosting are managed separately. This website publishes the Academy brand and product development note.
